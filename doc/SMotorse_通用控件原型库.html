14 属性面板（右侧检查器）

固定宽 320px，跟在画布或列表右侧。所有对象——轴、IO、气缸、运动步、流程节点、画面元件——的属性一律套这一套，不得各写各的。

14.2 数据类型 → 用什么控件

数据类型控件规则
短文本（名称）单行输入必填标 *；失焦校验同类对象内唯一；改名要么级联更新引用，要么禁止，不允许静默断链
长文本（说明/备注）文本域 3 行，可竖向拉伸永远不做富文本；不做字数限制提示，超长自然滚动
整数数字输入，右对齐，等宽数字只有存在明确步长（如通道号、次数）才配步进器；范围写在下方 11px 灰字
小数数字输入 + 固定小数位小数位由单位决定并强制对齐：mm/deg 三位、s 三位、% 与 ms 整数。失焦时补齐到固定位数
带单位数值数字输入 + 后缀单位（灰、不可编辑）单位绝不进输入框。单位随其他字段联动变化时（直线轴 mm / 旋转轴 deg）必须自动改
数值区间两个数字输入 + 中间「～」下限大于上限即时标红，错误文案挂在整行下方而不是某一个框
布尔 · 即时生效开关 Switch用于「启用/禁用」「反向/正向」这类拨一下就改变行为的量
布尔 · 表单项复选框用于「参与校验」「跟随主轴」这类随整体保存才生效的量。两者不可混用
枚举 2–3 项，标签 ≤4 字分段控件超过 3 项或标签更长一律改下拉，不要横向挤
枚举 4–8 项下拉选项顺序固定，不按使用频率动态排序
枚举 >8 项带搜索的下拉搜索框在下拉内部，不占字段行
枚举 + 可自定义下拉，末项「自定义…」选中后同一行原地变成输入框，不弹窗
引用单个对象
（点位 / 条件 / IO / 运动块）		下拉 + 🔍 选择器 + ↗ 跳转三件套缺一不可：选、找、跳。被引用对象已删除时显示红字「已失效」并保留原名，不得静默清空
引用多个对象标签列表 + 「添加」超过 3 个折叠为「+N」，点开是弹窗列表
只读派生值纯文本，无输入框边框与可编辑字段视觉必须有别；无数据显示 --.--- 而不是 0
复杂子对象「配置…」按钮 → 弹窗面板内嵌套不得超过两层；第三层一律弹窗
列表 / 表格型属性「编辑列表（3）」按钮 → 弹窗或跳页320px 放不下表格，不要塞微型表格进来
颜色色块 + 取色器仅生产画面元件使用
文件 / 路径只读输入 + 「浏览」路径过长中间省略，hover 显示全路径

14.3 分组规则

规则说明
组的顺序固定基本 → 映射/引用 → 参数 → 回零等专项 → 高级 → 只读信息。任何对象都按这个顺序，用户换个对象不用重新找
组数与字段数组数 ≤ 6，单组字段 ≤ 8。超出说明这个对象该拆，或该有一个独立的配置窗口
第一组「基本」默认展开且不可折叠——至少要能看见自己在改谁
高级组默认折叠。判定标准：90% 的现场调试不需要动它
只读信息组永远放最后，用 key–value 排版，不用输入框外观
折叠状态按对象类型记忆，不按单个对象记忆。切到另一个轴时展开状态保持一致
不允许组内再套组；用 Tab 分组（窄面板里的 Tab 会让人找不到东西）

14.4 四个必须实现的机制

机制做法
条件显隐与联动置灰并说明原因，不隐藏。字段消失会让人以为软件坏了。原因写在字段下方 11px 灰字，例：「绝对值编码器无需搜索原点」。只有整组都不适用时才隐藏整组
校验失焦触发，不做逐字符校验。错误：红框 + 字段下方红字，同时禁用全局保存。警告：黄框 + 黄字，不阻止保存。错误文案说清「哪儿错了 + 应该是多少」，不写「输入非法」
修改追踪改过的字段在标签左侧显示蓝点，hover 显示「原值 xxx · 点击还原」。面板顶部汇总「N 项改动」+「全部还原」。这是进入生产态前唯一能看清改了什么的地方
多选批量编辑选中多个同类对象时：值相同的字段正常显示；值不同的显示占位「多个值」且不预填；编辑后覆盖全部选中对象。名称这类唯一性字段整行禁用并说明「名称不支持批量修改」
